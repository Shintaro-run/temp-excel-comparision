# 障害ステータス集計（親 × 子）

障害一覧のシートを読み、親のステータス（J列）と子のステータス（L列）を、統合せずに並べて
クロス集計する Excel VBA です。実行すると、次の2つを出します。

- 「ステータス」シートに、クロス集計表と積み上げ縦棒グラフ（静的）
- 同じフォルダに、触れる・動く HTML ダッシュボード（棒が1本ずつ伸びる／件数・割合の切り替え／棒と表をクリックで親の掘り下げ／凡例をクリックで子の絞り込み）

ステータス名は J列・L列の記入欄から自動で拾います。固定の一覧は持たないので、名前が変わっても初期設定なしで反映されます。

集計する行は **F列に文字列がある行だけ** です。F列が空の行は完全に無視します。

## 使い方

1. Excel でブックを開く
2. Alt+F11 でエディタを開き、標準モジュールに `障害ステータス集計_併用_VBA.bas` の中身を貼り付け
3. マクロ「ステータス集計を作る」を実行

まず `.bas` の先頭にある【設定】で、シート名・列・開始行が実物と合っているか確認してください。
- SHEET_DATA＝データのシート名（既定「障害一覧」）
- FIRST_ROW＝データが始まる行（既定 3）
- COL_KEEP＝集計対象の判定列（F。ここに文字列がある行だけ集計）
- COL_AT＝親側のステータス（J列）／COL_NS＝子側のステータス（L列）

## 動作確認

Windows の Excel（バージョン16.0）で、末尾まで実行して確認済みです。ステータスの自動取得、
クロス集計表、積み上げグラフ、HTML ダッシュボードの生成まで動きます。


## ステータスを一時的にまとめる（HTMLダッシュボードだけの機能）

ダッシュボード上部の「ステータスをまとめる」を押すと、親側・子側それぞれで複数のステータスを
その場でまとめられます（数値は合計され、表とグラフに即反映）。

- まとめは複数作れます。まとめ名はその場で仮に付けられます（保存はされません）。
- 「まとめを全部解除」で一発で元に戻ります。
- **この操作はブラウザの表示だけで、Excel には一切影響しません。**


## PDF出力（A4）

ダッシュボード上部の「PDF出力（A4）」を押すと、ブラウザの印刷から A4（横）でPDFに保存できます。
図（積み上げ棒）と表（クロス集計・全列）が出ます。**まとめる前でも、まとめた後でも、
そのときの表示のままPDFになります。**操作ボタンやまとめパネルはPDFには出ません。


## まとめルールの保存・呼び出し

複数のまとめ（親側・子側のグループ一式）を「ルール」として名前を付けて覚えられます。

- 上部の **保存**（フロッピーのアイコン）で、いまのまとめをルール名を付けて保存します。
- **呼び出し**（フォルダのアイコン）で、保存したルールを選ぶと、そのまとめが**一括で適用**されます。
- ルールはこの端末のブラウザに覚えます。別の端末へ移すときや控えを取るときは「ファイルに書き出す／読み込む」を使います。
- **すべてブラウザ側だけの処理で、Excel には影響しません。**


## そのほかのダッシュボード機能

- **障害IDの表示**：棒の区画、または表のセルをクリックすると、そのマス（親×子）に入っている障害IDの一覧が出ます。
- **CSVコピー**：「CSVコピー」で、いまの表（まとめ・絞り込み後の状態）をCSVでクリップボードにコピーします（コピーできない環境では自動でCSVを保存）。
- **絞り込み・並べ替え**（「表示設定」）：子ステータス名のキーワードで列を絞り込み、行・列を「出現順／多い順／名前順」で並べ替えます。
- **ダーク表示・色覚に配慮した配色**（「表示設定」）：暗い配色に切り替え、見分けやすい配色に変更できます。
- **PDFの見出し**（「表示設定」）：タイトル・日付・メモを入れると、PDFの先頭に印刷されます。

いずれもブラウザ側の表示だけで、Excel には影響しません。


## Excelで文字化けするとき（インポートの文字コード）

Excel の VBE は「ファイルのインポート」で読むとき、Windows の既定文字コード（日本語版は Shift-JIS）で
読み込みます。そのため **UTF-8 の `.bas` をそのままインポートすると日本語が文字化け**します。
次のどちらかで回避してください。

- **貼り付け（確実）**：`障害ステータス集計_併用_VBA.bas` を GitHub で開き、Raw 表示で全文をコピー →
  VBE の標準モジュールへ貼り付け → **1行目 `Attribute VB_Name = ...` を削除**。
  クリップボードは Unicode なので化けません。
- **インポート用**：Shift-JIS 版の **`障害ステータス集計_併用_VBA_ShiftJIS.bas`** を
  「ファイル → ファイルのインポート」で取り込みます。日本語 Windows の Excel で化けずに入ることを実機で確認済みです。
  （この Shift-JIS 版は GitHub の画面上では文字化けして見えますが、インポート専用です。中身は UTF-8 版と同じです。）
